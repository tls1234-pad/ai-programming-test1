### scores_2026.csv의 열

| 열 | 뜻 | 자료형 |
|---|---|---|
| 학번 | 학생을 구분하는 번호 | 문자 |
| 이름 | 학생 이름 | 문자 |
| 반 | 학생이 속한 반. 정제 후 1반 또는 2반 | 문자 |
| 과목 | 평가 과목. 정제 후 수학, 영어, 프로그래밍 | 문자 |
| 점수 | 해당 과목의 성적. 정상 범위는 0~100점 | 정수 |

※ 원본에는 빈 점수가 있어 pandas로 읽으면 점수 열이 실수형으로 표시될 수 있다.
※ CP949 파일을 읽을 때는 encoding="cp949"를 지정한다.

### 원본 데이터에서 확인한 문제

- 전체 크기: 114행, 5열
- 점수가 비어 있는 행: 6개
- 모든 열이 완전히 같은 중복 행: 4개
- 정상 범위를 벗어난 점수: 4개
  - 999점: 3개
  - -5점: 1개
- 반 이름 뒤에 공백이 붙은 행: 2개
- 과목 이름 뒤에 공백이 붙은 행: 1개

원본의 반 값은 '2반', '1반', '1반 '으로 구분되어 있었다.
마지막 '1반 '은 끝에 공백이 붙어 있어 다른 값으로 인식되었다.

### 데이터 정제 기준

1. 원본을 보존하기 위해 복사본을 만들어 작업한다.
2. 점수가 비어 있는 행은 삭제한다.
   - 임의로 점수를 채우면 실제 반별 평균이 왜곡될 수 있기 때문이다.
3. 모든 열의 값이 완전히 같은 행은 첫 행만 남기고 나머지는 삭제한다.
4. 반과 과목 값의 앞뒤 공백을 제거한다.
5. 점수가 0 미만이거나 100을 초과하는 행은 삭제한다.

중복 제거를 먼저 하고 공백을 제거하는 순서로 처리한다.

### 정제 기록

| 단계 | 남은 행 수 | 해당 단계에서 삭제한 행 수 |
|---|---:|---:|
| 원본 | 114 | 0 |
| 빈 점수 제거 후 | 108 | 6 |
| 중복 제거 후 | 104 | 4 |
| 반·과목 공백 제거 후 | 104 | 0 |
| 범위 밖 점수 제거 후 | 100 | 4 |

114 = 100 + 6 + 4 + 4로 행 수가 일치한다.
정제 후 반은 2종류, 과목은 3종류가 남는다.

### 분석 결과

반별 점수 통계는 다음과 같다.

| 반 | 개수 | 평균 | 중앙값 | 최댓값 |
|---|---:|---:|---:|---:|
| 1반 | 50 | 78.24 | 78.00 | 98.00 |
| 2반 | 50 | 71.44 | 71.00 | 98.00 |

과목과 반을 함께 기준으로 묶은 평균은 다음과 같다.

| 과목 | 1반 평균 | 2반 평균 |
|---|---:|---:|
| 수학 | 60.00 | 64.00 |
| 영어 | 76.00 | 79.00 |
| 프로그래밍 | 84.00 | 88.00 |

정제된 데이터에서 수학 과목만 남기면 38행이다.

### 결과 검증

- 합계 일치:
  - 1반 점수 합계: 3912.0
  - 2반 점수 합계: 3572.0
  - 그룹 합계의 합: 3912.0 + 3572.0 = 7484.0
  - 전체 점수 합계: 7484.0
  - 두 값이 일치한다.

- 개수 일치:
  - 1반 50개 + 2반 50개 = 100개
  - 정제된 전체 행 수 100행과 일치한다.

- 스팟 체크:
  - 확인 대상: 1반 수학 평균
  - 점수: 62, 69, 60, 54, 61, 59, 61, 54
  - 직접 계산: (62+69+60+54+61+59+61+54) / 8 = 60.0
  - 그룹화 결과인 60.0과 일치한다.

### mini.csv 검증

| 항목 | 결과 |

| 원본 행 수 | 10행 |
| 삭제한 행 | 빈 점수 1행, 중복 1행, 범위 밖 점수 1행 |

| 1반 평균 | (90+70+80+80) / 4 = 80.0 |

### 분석하면서 발견한 점

전체 평균은 1반이 78.24점으로 2반의 71.44점보다 높았다.
하지만 수학, 영어, 프로그래밍을 각각 비교하면 모두 2반 평균이 높았다.

반마다 과목별 데이터 수가 달라서 이런 결과가 나타났다.
1반은 전체 50개 중 프로그래밍이 30개이고,
2반은 전체 50개 중 수학이 30개이다.
평균 점수가 높은 프로그래밍 자료의 비중이 1반에서 더 크므로,
전체 평균만 보고 어느 반이 더 잘했다고 단정하기 어렵다.
