데이터 명세서에서 정한 처리 기준을 바탕으로 작성하였다.
분석 목적은 반별 성적을 비교하고, 계산 결과를 검증하는 것이다.

---------------------------------------------------------
A. 정제 (STEP 2)
---------------------------------------------------------
[역할]
너는 파이썬 데이터 처리를 돕는 조교다.
대학교 1학년이 읽고 이해할 수 있는 코드를 작성해라.

[목표]
아래 명세대로 CSV를 정제하는 함수 정제(df)를 만들어라.
이 함수는 정제된 DataFrame을 반환해야 한다.
작성한 함수는 analysis.py에 넣을 수 있게 제시해라.

[데이터]
  파일: scores_2026.csv
  인코딩: UTF-8
  원본 크기: 114행 5열
  열: 학번, 이름, 반, 과목, 점수

  학번: 학생을 구분하는 번호이며 문자로 취급한다.
  이름: 학생 이름이며 문자이다.
  반: 소속 반이며 정제 후 '1반' 또는 '2반'이어야 한다.
  과목: 정제 후 '수학', '영어', '프로그래밍' 중 하나이다.
  점수: 과목별 성적이며 정상 값은 0 이상 100 이하의 정수이다.

  점수가 비어 있는 행은 6개이다.
  모든 열이 완전히 같은 중복 행은 4개이다.
  정상 범위를 벗어난 점수는 999점 3개와 -5점 1개이다.
  반 이름 뒤에 공백이 붙은 행은 2개이다.
  과목 이름 뒤에 공백이 붙은 행은 1개이다.

  점수 열은 결측값 때문에 pandas에서 실수형으로 읽힐 수 있다.
  90.0처럼 정수와 같은 값을 가진 점수는 정상 값으로 취급한다.

[처리 규칙]
  1) 원본 df를 복사한 뒤 복사본으로 작업한다.
  2) 점수가 비어 있는 행은 삭제한다.
     임의로 점수를 채우면 반별 평균을 왜곡할 수 있기 때문이다.
  3) 모든 열이 완전히 같은 행은 첫 행만 남기고 나머지는 삭제한다.
  4) 반과 과목 값의 앞뒤 공백을 제거한다.
  5) 점수가 0 미만이거나 100을 초과하는 행은 삭제한다.
     0점과 100점은 정상 점수이므로 남긴다.

  위의 처리 순서를 지켜라.
  특히 중복 제거를 먼저 하고 반과 과목의 공백을 제거해라.

[제약]
  - pandas만 사용한다.
  - 원본 df를 직접 수정하지 마라.
  - 시작 행 수와 각 처리 단계가 끝난 뒤 남은 행 수를 print해라.
  - 각 단계의 의미를 한 줄짜리 주석으로 설명해라.
  - 행 수는 실제 DataFrame에서 계산해서 출력해라.
  - 결과가 100행이 되도록 임의로 행을 자르거나 추가하지 마라.
  - CSV를 읽을 때 학번 열은 문자로 읽어라.

D. 통계 (STEP 3-③)
---------------------------------------------------------
정제된 df를 '반'으로 묶어 점수의 개수, 평균, 중앙값, 최댓값을
한 표로 출력하는 코드를 작성해라.
통계 결과는 소수 둘째 자리까지 반올림해라.

함수 이름은 반별평균(df)로 해라.
함수 안에서 반별 통계표를 print하고,
반 이름을 키로 하는 평균값 딕셔너리 또는 Series를 반환해라.
예를 들어 반환값에서 ['1반']으로 1반 평균을 확인할 수 있어야 한다.

추가로 다음 검증 값을 출력하는 코드도 제시해라.

  1) 반별 점수 합계의 합과 전체 점수 합계
  2) 반별 점수 개수의 합과 전체 행 수
  3) 1반 수학 점수 목록, 합계, 개수, 평균

모든 수치는 전달받은 df에서 직접 계산해라.
정제 함수와 반별평균 함수는 analysis.py에서 불러올 수 있게 해라.
analysis.py의 실행 예시는 if __name__ == "__main__": 아래에 두어,
테스트에서 import할 때 실행 예시까지 자동 실행되지 않게 해라.
