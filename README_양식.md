# 성적 CSV 읽기와 pytest 테스트

## ① 무엇을 하나요 (What)

성적 CSV 파일을 읽어 이름이 있고 점수가 0~100 사이의 정수인 성적을 모으고, 조건을 만족하지 않는 행은 건너뛴 이유와 함께 기록합니다.

## ② 왜 만들었나요 (Why)

성적 파일에는 빈 점수, 범위를 벗어난 점수, 숫자가 아닌 값 등이 섞여 있을 수 있습니다. 이런 입력 때문에 전체 처리가 중단되지 않도록 정상 성적과 잘못된 입력의 기록을 나누어 확인하고자 했습니다. 또한 같은 이름이 서로 다른 사람일 수 있으므로 동명이인의 성적을 모두 보존하도록 했습니다.

## ③ 어떻게 쓰나요 (How)

Python 3가 설치된 환경에서 사용합니다. VS Code로 저장소 폴더를 열고 터미널을 실행합니다. 아래 명령은 `load_scores.py`와 CSV 파일들이 있는 폴더에서 입력합니다.

### 테스트 도구 설치

```bash
python -m pip install pytest pytest-cov
```

### 프로그램 실행

```bash
python load_scores.py scores.csv
```

제공된 `scores.csv`로 실행하면 유효한 성적 5개와 건너뛴 행 5개가 출력됩니다. 같은 이름의 성적은 둘 다 남고, 빈 줄은 건너뛴 기록에 포함되지 않습니다.

다른 입력 파일을 확인하려면 파일 이름을 바꿉니다.

```bash
python load_scores.py empty.csv
python load_scores.py weird.csv
```

`empty.csv`는 유효한 성적 0개와 건너뛴 행 0개, `weird.csv`는 유효한 성적 2개와 건너뛴 행 7개가 나오는 입력입니다.

## ④ 어떻게 테스트하나요

`test_load_scores.py`를 `load_scores.py` 및 CSV 파일들과 같은 폴더에 놓고 다음 명령을 실행합니다.

```bash
python -m pytest test_load_scores.py -v
```

테스트 함수는 5개이고, 점수 경계값 함수가 6가지 입력으로 실행되므로 총 10개 테스트가 실행됩니다. 정상 결과는 `10 passed`입니다. 실행 시간은 환경에 따라 다릅니다.

검사 내용은 정상 성적과 건너뛴 기록, 헤더만 있는 파일, 존재하지 않는 파일의 예외, 이상한 입력, 점수 경계값(-1, 0, 1, 99, 100, 101)입니다.

### 내 컴퓨터에서 실행한 결과

```text
[10 passed in 0.55s]
```

### 커버리지 확인

```bash
python -m pytest test_load_scores.py --cov=load_scores --cov-report=term-missing
```

`Cover`는 실행된 코드의 비율이고, `Missing`은 테스트가 실행하지 않은 줄 번호입니다. 이 테스트들은 `load_scores()` 함수를 호출하므로, 프로그램을 직접 실행할 때만 동작하는 `if __name__ == "__main__":` 아래 출력 부분은 실행되지 않은 줄로 표시됩니다.
